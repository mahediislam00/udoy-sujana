# Udoy & Sujana — Wedding Invitation

A single page that plays the invitation video full screen on phones and desktops.

- `index.html` — the page
- `invitation.mp4` — the video (replace it with a new version using the same name)
- `poster.jpg` — still image shown before the video starts and in link previews

Deploy: push this folder to a GitHub repository, then import it in Vercel (Framework preset: Other, no build command).
